    Просунутий рівень¶

    BotAPI вже став звичайним? Починаєте свій день з читання документації? Прості боти набридли, а до складних страшно приступати?

    Представляю вашій увазі новий курс «Telegram-боти на Python: поглиблений рівень», де я виступаю одним з авторів. На даний момент курс знаходиться в ранньому доступі, коли написано приблизно 80% матеріалу, але незабаром він поповниться новими модулями. Вже зараз ви можете отримати знання, які знадобляться не лише для написання ботів, але також і в інших проектах на Python.

    Ось лише деякі приклади:

    • aiogram-dialog

      Створюйте красиві й зручні інтерфейси в межах вікна месенджера за допомогою aiogram-dialog.

    • Тестування

      Перевіряйте коректність логіки вашого коду без набридлого ручного тестування та «ловління багів на проде».

    • Docker

      Збирайте Docker-контейнери для швидкого й зручного розгортання та обміну з іншими користувачами. Автоматизуйте збірку в GitHub і GitLab. Працюйте з Docker Compose.

    • Локалізація

      Навчайте своїх ботів розмовляти з користувачами різними мовами. У цій справі вам допоможуть Babel та Project Fluent.

    • Черги

      Використовуйте черги та брокери повідомлень (RabbitMQ, NATS), щоб виносити різні завдання в окремі мікросервіси для підвищення надійності та гарантій доставки.

    • Робота з СУБД

      Використовуйте сучасні бази даних та інструменти для роботи з ними для швидкого й ефективного зберігання інформації про користувачів та їхній контент
