# Написання Telegram-ботів з aiogram 3.x

**Мови README:** [RU](README.md) · [EN](README.en.md) · [UK](README.uk.md) · [ZH](README.zh.md)

Це книга з розробки Telegram-ботів на Python з використанням **[aiogram 3.x](https://github.com/aiogram/aiogram/tree/dev-3.x)** (поточна базова версія прикладів: **3.27.0+**).

Книгу можна читати тут: https://mastergroosha.github.io/aiogram-3-guide/  
Вихідні тексти для всіх глав розміщені [у папці code](https://github.com/MasterGroosha/aiogram-3-guide/tree/master/code).

Попередні версії:
* aiogram 2.x (2019-2021): https://mastergroosha.github.io/aiogram-2-guide/
* pyTelegramBotAPI (2015-2019): https://mastergroosha.github.io/telegram-tutorial/

---
Доступні мови інтерфейсу та перекладу: **RU**, **EN**, **UK**, **ZH** (китайський переклад у процесі наповнення).
---

Книга зібрана за допомогою [mkdocs-material](https://squidfunk.github.io/mkdocs-material/).

### Швидкий старт (pip)

```bash
python -m pip install -r requirements.txt
mkdocs build --strict
```

### Швидкий старт (uv)

```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
mkdocs build --strict
```
