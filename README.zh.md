# 使用 aiogram 3.x 编写 Telegram 机器人

**README 语言：** [RU](README.md) · [EN](README.en.md) · [UK](README.uk.md) · [ZH](README.zh.md)

这是一本使用 **[aiogram 3.x](https://github.com/aiogram/aiogram/tree/dev-3.x)** 与 Python 开发 Telegram 机器人的教程（当前示例基线版本：**3.27.0+**）。

在线阅读地址：https://mastergroosha.github.io/aiogram-3-guide/  
所有章节源文件位于 [code 目录](https://github.com/MasterGroosha/aiogram-3-guide/tree/master/code)。

历史版本：
* aiogram 2.x (2019-2021): https://mastergroosha.github.io/aiogram-2-guide/
* pyTelegramBotAPI (2015-2019): https://mastergroosha.github.io/telegram-tutorial/

---
当前支持的界面/翻译语言：**RU**、**EN**、**UK**、**ZH**（中文内容仍在持续补充）。
---

本书使用 [mkdocs-material](https://squidfunk.github.io/mkdocs-material/) 构建。

### 快速开始（pip）

```bash
python -m pip install -r requirements.txt
mkdocs build --strict
```

### 快速开始（uv）

```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
mkdocs build --strict
```
