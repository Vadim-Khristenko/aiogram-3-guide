# Payments (Telegram Stars)

In this directory, you'll find the source files for the chapter https://vadim-khristenko.github.io/aiogram-3-guide/en/payments/

To run the bot (Python 3.11 or higher required), copy the `settings.example.toml` file as `settings.toml` and fill it with your values. Then you can run (from the virtual environment) with the command:

```python
CONFIG_FILE_PATH=/path/to/settings.toml python -m bot
```

Also in the repository is the [donatebot.example.service](donatebot.example.service) file
for running through Systemd.
