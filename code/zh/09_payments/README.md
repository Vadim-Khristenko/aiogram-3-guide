# 支付（Telegram Stars）

在此目录中，您可以找到本章节的源代码：https://vadim-khristenko.github.io/aiogram-3-guide/zh/payments/

要运行机器人（需要 Python 3.11 及以上），请将 `settings.example.toml` 文件复制并命名为
`settings.toml`，然后填入您自己的值。之后可以运行（在 venv 中）：

```python
CONFIG_FILE_PATH=/path/to/settings.toml python -m bot
```

仓库中还有 [donatebot.example.service](donatebot.example.service)
文件，可通过 Systemd 运行。
