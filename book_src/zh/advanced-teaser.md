# 高级级别

您已经熟悉 BotAPI 了？您从阅读文档开始每一天？简单的机器人已经厌倦，而复杂的机器人令人害怕？

我向您介绍一个新课程"[Python Telegram 机器人：高级级别](https://stepik.org/a/153850?utm_source=aiogram3guide&utm_medium=web&utm_campaign=promo_page)"，我是作者之一。目前，该课程处于**早期访问**阶段，已写入约 80% 的材料，但很快将添加新模块。现在您已经可以获得对不仅编写机器人有用的知识，而且对 Python 中的其他项目也有用。

以下是一些示例：

<div class="grid cards" markdown>

-   :material-widgets:{ .lg .middle } __aiogram-dialog__

    ---

    使用 [aiogram-dialog](https://github.com/Tishka17/aiogram_dialog) 在信使窗口框架内创建漂亮且方便的界面。

  - :simple-pytest:{ .lg .middle } __测试__

      ---

      检查代码逻辑的正确性，无需繁琐的手动测试和"在生产中捕获错误"。

-   :simple-docker:{ .lg .middle } __Docker__

    ---

    构建 Docker 容器以快速方便地部署和与其他用户共享。在 GitHub 和 GitLab 中自动化构建。使用 Docker Compose。

-   :material-translate-variant:{ .lg .middle } __本地化__ 

    ---

    教您的机器人用不同的语言与用户交流。
    [Babel](https://github.com/python-babel/babel)
    和 [Project Fluent](https://projectfluent.org/) 将帮助您。

-   :simple-natsdotio:{ .lg .middle } __队列__ 

    ---

    使用队列和消息代理（RabbitMQ、NATS），
    将各种任务放入单独的微服务中
    以增加可靠性和交付保证。

-   :material-database:{ .lg .middle } __数据库工作__ 

    ---

    使用现代数据库和工具来处理它们
    以快速有效地存储有关用户及其内容的信息

</div>
