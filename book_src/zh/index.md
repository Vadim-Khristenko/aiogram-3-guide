# **欢迎！** {: id="welcome" }

您现在看到的是我，[Groosha](https://mastergroosha.github.io/)，称之为关于使用 [aiogram](https://github.com/aiogram/aiogram) 框架用 Python 创建 Telegram 机器人的书。这本书可以视为学习材料，根据需要参考各个章节，但第一次阅读时，我建议按照章节在此文本左侧列出的顺序进行。

这是本指南的第三个版本。[第一个](https://mastergroosha.github.io/telegram-tutorial/)版本于 2015-2017 年编写，适用于 [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) 库，[第二个](https://mastergroosha.github.io/aiogram-2-guide/)版本于 2019 年发布，适用于 aiogram 2.x。在这个更新的书版本中，我们将使用 aiogram 版本 3，它于 2023 年 9 月 1 日正式发布。

**这本书是为谁写的？**  
假设您熟悉一般编程和 Python 语言，知道什么是 "venv" 和 "pip"，并且能够理解和修复 _SyntaxError_ 和 _IndentationError_ 这样的"初级"错误。在互联网上找几个 Python 课程，学完它们，然后再开始写机器人，这样可以节省时间和精力。

在所有章节中，我们将使用 GNU/Linux 系列的操作系统，例如 [Ubuntu](https://ubuntu.com/)、Python 3.11（在虚拟环境中）和开发环境 [PyCharm](https://www.jetbrains.com/ru-ru/pycharm/download/)，当然 [Visual Studio Code](https://code.visualstudio.com/) 也可以。与此同时，Windows 用户不会被遗漏：所有与代码相关的内容都能在您的计算机上正常工作，对于特定的东西，比如 systemd，您可以在 [VirtualBox](https://www.virtualbox.org) 中使用 Ubuntu。

本书的文本和 [相应仓库](https://github.com/MasterGroosha/aiogram-3-guide) 中的源代码完全免费，在 MIT 许可证下发布，任何人都可以下载、修改和使用于任何目的。
