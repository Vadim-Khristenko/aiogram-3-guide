# Просунутий рівень

BotAPI вже став звичайним? Починаєте свій день з читання документації? Прості боти набридли, 
а до складних страшно приступати? 

Представляю вашій увазі новий курс «[Telegram-боти на Python: поглиблений рівень](https://stepik.org/a/153850?utm_source=aiogram3guide&utm_medium=web&utm_campaign=promo_page)», 
де я виступаю одним з авторів. На даний момент курс знаходиться в **ранньому доступі**, коли написано приблизно 80% матеріалу, але 
незабаром він поповниться новими модулями. Вже зараз ви можете отримати знання, які знадобляться не лише для написання ботів, 
але також і в інших проектах на Python. 

Ось лише деякі приклади:

<div class="grid cards" markdown>

-   :material-widgets:{ .lg .middle } __aiogram-dialog__

    ---

    Створюйте красиві й зручні інтерфейси в межах вікна месенджера за допомогою 
    [aiogram-dialog](https://github.com/Tishka17/aiogram_dialog).

  - :simple-pytest:{ .lg .middle } __Тестування__

      ---

      Перевіряйте коректність логіки вашого коду без набридлого ручного тестування та 
      «ловління багів на проде».

-   :simple-docker:{ .lg .middle } __Docker__

    ---

    Збирайте Docker-контейнери для швидкого й зручного розгортання та обміну 
    з іншими користувачами. Автоматизуйте збірку в GitHub і GitLab. Працюйте з Docker Compose.

-   :material-translate-variant:{ .lg .middle } __Локалізація__ 

    ---

    Навчайте своїх ботів розмовляти з користувачами різними мовами. 
    У цій справі вам допоможуть [Babel](https://github.com/python-babel/babel)
    та [Project Fluent](https://projectfluent.org/).

-   :simple-natsdotio:{ .lg .middle } __Черги__ 

    ---

    Використовуйте черги та брокери повідомлень (RabbitMQ, NATS),
    щоб виносити різні завдання в окремі мікросервіси для 
    підвищення надійності та гарантій доставки.

-   :material-database:{ .lg .middle } __Робота з СУБД__ 

    ---

    Використовуйте сучасні бази даних та інструменти для роботи з ними 
    для швидкого й ефективного зберігання інформації про користувачів та
    їхній контент


</div>
