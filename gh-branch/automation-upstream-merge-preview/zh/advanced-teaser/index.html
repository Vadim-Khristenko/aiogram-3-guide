    高级级别¶

    您已经熟悉 BotAPI 了？您从阅读文档开始每一天？简单的机器人已经厌倦，而复杂的机器人令人害怕？

    我向您介绍一个新课程"Python Telegram 机器人：高级级别"，我是作者之一。目前，该课程处于**早期访问**阶段，已写入约 80% 的材料，但很快将添加新模块。现在您已经可以获得对不仅编写机器人有用的知识，而且对 Python 中的其他项目也有用。

    以下是一些示例：

    • aiogram-dialog

      使用 aiogram-dialog 在信使窗口框架内创建漂亮且方便的界面。

    • 测试

      检查代码逻辑的正确性，无需繁琐的手动测试和"在生产中捕获错误"。

    • Docker

      构建 Docker 容器以快速方便地部署和与其他用户共享。在 GitHub 和 GitLab 中自动化构建。使用 Docker Compose。

    • 本地化

      教您的机器人用不同的语言与用户交流。 Babel 和 Project Fluent 将帮助您。

    • 队列

      使用队列和消息代理（RabbitMQ、NATS）， 将各种任务放入单独的微服务中 以增加可靠性和交付保证。

    • 数据库工作

      使用现代数据库和工具来处理它们 以快速有效地存储有关用户及其内容的信息
